## DESKRIPSI PROGRAM

Program ini merupakan tugas pembuatan halaman Curriculum Vitae (CV) dan Form Registrasi menggunakan HTML semantik dan CSS. Proyek ini mengusung tema Monochrome Elegant dengan warna dominan hitam, putih, dan abu-abu untuk memberikan kesan dokumen profesional yang bersih, tegas, dan minimalis. HTML digunakan secara khusus untuk membangun kerangka dan struktur halaman, yang meliputi elemen header, navigasi sidebar, bagian riwayat pendidikan dan pengalaman, serta sekumpulan elemen form pendaftaran akun yang komprehensif. Sementara itu, CSS diterapkan untuk mengatur tata letak halaman menggunakan metode CSS Grid guna membagi proporsi antara sidebar dan konten utama, sekaligus mendefinisikan gaya tipografi melalui paduan font jenis Serif untuk judul dan Sans-Serif untuk teks paragraf.
