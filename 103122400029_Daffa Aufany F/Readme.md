# Curriculum Vitae Daffa Aufany Febrianto

Halaman CV sederhana berbasis HTML dan CSS yang menampilkan biodata, profil singkat, riwayat pendidikan, keahlian, pengalaman, media sosial, dan informasi kontak.

## Isi Folder

- `index.html` — struktur dan konten halaman CV.
- `style.css` — tampilan halaman, termasuk warna, tata letak, tabel, dan tautan.
- `foto.jpg` — foto profil yang ditampilkan pada bagian biodata.

## Menjalankan

Buka `index.html` menggunakan browser. Pastikan `style.css` dan `foto.jpg` tetap berada di folder yang sama.
