## 3. Deskripsi Program

Program ini merupakan halaman Curriculum Vitae satu halaman yang dibuat menggunakan HTML dan CSS. HTML menyusun konten CV ke dalam bagian profil, pengalaman dan proyek, pendidikan, kontak, keterampilan, serta karakter. CSS mengatur tata letak, warna, ukuran teks, jarak, dan elemen visual agar informasi mudah dibaca. Media query digunakan untuk menyesuaikan tampilan pada layar kecil, sedangkan aturan `@media print` mengatur halaman untuk dicetak pada ukuran A4.
